# Historical UI audits

Everything under this directory is dated evidence from an earlier OrchestrOS revision. The reports, JSON captures, and screenshots are intentionally preserved as they were recorded; they are **not current product documentation**.

In particular, the October 2026 captures predate Round Robin preemption, Reactive/ML comparison, the current top-bar/sidebar shell, the warm theme, and the latest test suites. Use the active guides in [`docs/`](../README.md) for current behavior.
